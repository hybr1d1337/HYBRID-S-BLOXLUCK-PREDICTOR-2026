## 📖 About
**Bloxluck Predictor** is an advanced browser extension created for educational and research purposes. It features a custom 3D coin flip prediction mechanism and a modern interface built with standard web technologies.

---

## 🛠️ Installation

1. Click the **DOWNLOAD ZIP** button above or download the project manually from the top right **(Code -> Download ZIP)** and extract it.
2. Open Google Chrome and navigate to:
   `chrome://extensions/`
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click on the **Load unpacked** button in the top-left corner.
5. Select the extracted project folder.
